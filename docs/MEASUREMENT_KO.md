# 실제 평가 결과와 해석

## 평가 범위

- 원본 LogAgent의 관측 정규화, T1~T4, 실측 온톨로지, 가설, Thread 점수화와 Top-1 선택 구조를 OpenRCA에 맞게 이식했습니다.
- Agent RCA Bench v34와 같은 OpenRCA2 10개 및 RCA100 4개 사례를 사용했습니다.
- 14개 독립 사례를 각각 두 번 실행했습니다. 반복 28회를 독립 표본 28개로 간주하지 않습니다.
- 원본 파일 158개 모두 공개 선택 fixture의 SHA256과 일치했습니다.
- LLM 호출, 원격 운영 DB, Neo4j 서버 없이 Python으로 평가했습니다.
- 정답 파일은 분석 입력에서 제외했으며, 분석 코드와 YAML을 고정하고 모든 예측을 봉인한 뒤 채점했습니다.

## 정답률

| 평가 대상 | 정답/전체 | 원인 위치·기전 일치율 | 원인 위치 일치 |
|---|---:|---:|---:|
| OpenRCA2 | 9/10 | **90.00%** | 10/10 |
| RCA100 | 2/4 | **50.00%** | 2/4 |
| 전체 | 11/14 | **78.57%** | 12/14 |

실행 오류는 0건, 기권은 1건입니다. 2회 반복의 전체 예측 파일 해시는 모든 사례에서 일치했습니다. 전체 정답률의 Wilson 95% 구간은 **52.41%~92.43%**입니다. 사례 수가 적으므로 이 숫자를 일반적인 운영 장애 해결 확률로 해석할 수 없습니다.

## 실패한 세 사례

| 사례 | 정답 | 예측 | 확인된 한계 |
|---|---|---|---|
| `semantic-rca-transfer-002` | `reservation`의 워크로드 재시작 | 같은 `reservation`의 의존 서비스 사용 불가 | 원인 위치는 맞았지만 ready 상태와 재시작 관측의 기전 구분에서 오분류했습니다. |
| `semantic-rca-transfer-013` | 인프라 노드의 디스크 I/O 저하 | 근거 부족으로 기권 | 현재 규칙이 요구하는 직접 I/O 전이 근거를 찾지 못했습니다. 원인을 임의로 채우지 않았습니다. |
| `semantic-rca-transfer-014` | 인프라 노드 사용 불가 | `prometheus-64498db647-jw4md`의 메모리 압박 | 관측된 다른 자원 이상을 선택했으며 실제 노드 장애 위치와 기전을 모두 놓쳤습니다. |

이는 저장된 예측과 정답 비교 결과의 설명입니다. 마지막 사례에서 메모리 압박이 실제 장애 원인이었다고 주장하지 않습니다. 실패 사례를 본 뒤 가중치나 규칙을 수정해 같은 결과를 다시 채점하지 않았습니다.

## 수치의 의미

- 원인 범위, 실제 객체 또는 방향 있는 간선, 장애 분류, 장애 기전이 모두 맞아야 정답입니다.
- 기권과 실행 실패도 전체 분모에 포함합니다.
- 점수는 원래 운영 코드 그대로의 성능이 아니라 **사용자 아키텍처를 OpenRCA에 적응시킨 새 구현의 최초 측정치**입니다.
- 공개 데이터의 스키마와 장애 분류를 참고해 구성했습니다. 비공개 holdout 평가나 전체 OpenRCA2 평가는 수행하지 않았습니다.
- 공개 모델의 Capability 지표, 에이전트 도구 호출 수, SQL 근거 검증기와 동일한 실험은 아닙니다. 따라서 78.57%를 공개 모델의 종합 점수와 직접 비교하지 않습니다.
- Thread의 근거 지지 점수는 정답 확률이나 검증된 인과 확률이 아닙니다.

## 재현 기록

- `results/v1/protocol.json`: 분석 시작 시 고정한 코드·설정 해시.
- `results/v1/source_audit.json`: 원본 158개 파일의 해시 대조 결과.
- `results/v1/results.json`: 사례별 예측, 정답 비교, 근거 통계와 원본 예측 해시.
- `provenance/measurement_history.json`: 서비스 식별자 결합을 수정하면서 무효화된 초기 실행과 최종 실행 구분.
- `provenance/runtime.json`, `uv.lock`: 실행 환경과 의존성.

공개 결과에는 원본 telemetry 행과 전체 호출 topology를 포함하지 않습니다. 근거 통계와 source 참조 해시를 보존하므로 원본을 다시 내려받아 검증할 수 있습니다.
