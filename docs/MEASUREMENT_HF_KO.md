# 실제 HF LLM 측정: 엄격한 진단 계약을 포함한 결과

Hugging Face의 공개 Qwen3-1.7B Q8 가중치를 사용해 원저장소의 선정 RCA 사례 14개에서 실제 모델 추론 56회를 완료했습니다. 단일 경량 모델의 별도 실험이며, 원래 6개 API 모델 실험의 재현으로 표시하지 않습니다.

| 데이터셋 | 독립 사례 | 관측 요약 + LLM | LogAgent 후보 + LLM |
|---|---:|---:|---:|
| OpenRCA2 | 10개 | 0/20, 0.00% | 6/20, 30.00% |
| RCA100 | 4개 | 0/8, 0.00% | 2/8, 25.00% |
| 전체 | 14개 | 0/28, 0.00% | 8/28, 28.57% |

각 조건에서 사례별 seed 17·29로 두 번 생성했습니다. 28회 실행은 독립 사례 28개를 뜻하지 않습니다. 모든 실행을 분모에 포함하며, 정확도에 유리한 반복만 고르지 않았습니다.

## 출력 계약 실패를 함께 읽어야 합니다

| 조건 | 전체 출력 | 원본 진단 구조 통과 | 구조 위반으로 거부 | 구조 통과 후 정답 |
|---|---:|---:|---:|---:|
| 관측 요약 + LLM | 28개 | 0개 | 28개 | 0개 |
| LogAgent 후보 + LLM | 28개 | 9개 | 19개 | 8개 |

두 조건 전체에서 47개 출력이 원본 `Diagnosis`의 위치 필드 상호배타 규칙을 위반했습니다. 30개는 방향 간선을 원인으로 선언하면서 `causal_component`도 채웠고, 15개는 컴포넌트를 원인으로 선언하면서 간선 필드도 채웠으며, 2개는 인프라 노드를 선언하면서 간선 필드도 채웠습니다. 정답 컴포넌트와 간선의 두 끝점은 서로 다른 출력 필드이며, 동시에 나열한 것을 복수 정답으로 인정하지 않습니다.

HF JSON grammar는 필드 타입과 enum을 제한하지만 이 상호배타 조건을 생성 단계에서 강제하지 않았습니다. 따라서 이 측정에는 작은 모델의 진단 추론과 구조화 출력 준수 능력이 함께 반영됩니다. 위반 출력을 사후 보정하거나, 여러 필드 중 정답과 가까운 것만 고르지 않았습니다. 이 결과만으로 일반적인 아키텍처 우월성이나 원인 추론 능력의 차이를 주장할 수 없습니다.

원본 `Diagnosis.model_validate`가 47개 위반 출력을 거부했고, 구조가 유효한 9개 답변에는 고정 원저장소 `evaluate_transfer_run`을 적용했습니다. 공개 JSON의 `scoring_errors`는 이번 실험에서 모두 이 구조 검증의 `ValidationError`입니다. 채점 인프라 예외는 0개입니다. 별도 `contract_audit.json`에 이 구분을 남겼습니다.

## 데이터·모델·실행 증거

- 원저장소 benchmark commit: `fdfbca65c87c36c6b06bddfa6d611544f13bfa34`.
- 같은 OpenRCA2 10개와 RCA100 4개 사례·시각 구간·원본 파일 158개의 SHA256을 유지했습니다.
- 모델: `Qwen/Qwen3-1.7B-GGUF@90862c4b9d2787eaed51d12237eafdfe7c5f6077`, 공식 Q8 가중치 SHA256 `061b54daade076b5d3362dac252678d17da8c68f07560be70818cace6590cb1a`.
- 추론 코드 commit: `9653684a77395451687dec51df2cb11c9c7cb9d7`.
- 추론 실행: https://github.com/dooyoung94/openrca_logagent/actions/runs/39402033849
- 56개 봉인 예측의 오프라인 집계: https://github.com/dooyoung94/openrca_logagent/actions/runs/39403123956
- 집계 코드는 `84f6fb9fe0fc3b5e7b34be556af997f835773407`, 원본 채점기가 지원하는 Python 3.11에서 실행했습니다.
- 초기 집계 단계의 Python 버전 문제는 이미 저장된 56개 예측을 그대로 사용해 해결했습니다. 집계를 위해 모델을 다시 호출하지 않았습니다.

원본 관측 행·요약 패킷·LLM 자유 서술 원문·가중치는 공개 저장소에 포함하지 않습니다. 공개 결과는 모델이 생성한 진단 필드·예측 해시·토큰 집계·공식 구조 판정·정답 판정을 보존합니다. 초기 중단 시도와 전처리 호환성 수정은 `experiments/hf_execution_history.json`에 기록했습니다. Arrow 변환 수정 뒤에도 14개 입력 패킷이 모두 바이트 단위로 동일함을 검증했습니다.

## 원저장소와의 비교 단위

원저장소의 전체 사례 항목은 22개이며, 보조 검색·관계 탐색 8개와 최종 RCA 14개로 구성됩니다. 이 실험은 같은 최종 RCA 14개를 사용합니다. 원저장소의 6개 모델 합산 분모는 조건당 OpenRCA2 120회, RCA100 48회이고, 이번 단일 모델 실험은 각각 20회·8회입니다.

원본 Raw·Semantic Graph는 실제 도구 호출을 포함하는 조사 인터페이스입니다. 이번 두 조건은 사전 집계 관측 요약을 읽는 단일 완성 호출이며, LogAgent 조건에 고정 후보 Thread를 추가했습니다. 후보 생성기는 공통 요약에서 생략된 원본 관측도 분석할 수 있으므로 정보량이 통제된 LLM 추론 비교로 해석하지 않습니다. SQL 근거 적격성·Capability·원본 효율 지표는 평가하지 않았습니다.

결과를 본 뒤 같은 사례의 모델·프롬프트·구조 규칙을 수정해 주 결과를 대체하지 않았습니다. 출력 계약을 개선하는 후속 실험을 한다면 이번 결과를 남기고 새로운 실험으로 구분해야 하며, 논문의 일반화 주장은 미사용 사례와 더 큰 모델에서 검증해야 합니다.
