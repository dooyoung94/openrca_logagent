## 비교할 때의 범위

- 이 수치는 과거 공개된 실행입니다. 새 LogAgent 실행과 시간·SDK·모델 상태가 맞춰진 paired 비교가 아닙니다.
- 새 LLM 비교는 같은 시점에 네 arm을 다시 실행한 기록으로 별도 생성합니다.
- 현재 Python 이식본의 구조화 진단 결과는 원저장소 `evaluate_transfer_run`으로 재검증했습니다. OpenRCA2 9/10, RCA100 2/4가 유지됐습니다. SQL 근거 적합성과 LLM 실행 신뢰도를 충족했다는 뜻은 아닙니다.
